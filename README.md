# John Ugbor — Personal Engineering Portfolio

A responsive, dark editorial portfolio built with Vite, React, TypeScript, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Add `johnugbor.com` and `www.johnugbor.com` in Vercel project settings.
7. Configure the DNS records Vercel provides at your domain registrar.
